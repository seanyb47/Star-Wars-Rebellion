# Canon

Sean's own source documents, dropped in on 16 September with *"Here are some
files I've made in ChatGPT, I use them for art... treat them as canon."*
They are the authority. Where anything in this repository disagrees with them,
this folder wins and the repository is wrong.

| File | What it settles |
|---|---|
| `project-readme.docx` | The source-of-truth order, the project's hard overrides, the default art style, the faction quick reference. |
| `art-direction-guide-v2.2.pdf` | Visual north star, the ten visual laws, faction identity and palettes, sigil reproduction, game-scale readability, supernatural language. |
| `naval-art-master-v2.pdf` | Ship production rules: geometry, silhouette, the Crown II programme, the captured-ship rule, the full fleet roster and which hulls are canonical against which are proposed. |
| `faction-sigils-v1.pdf` | The two official faction marks and how to reduce them for sails, flags, monochrome and small icons. |
| `art-direction-board.png` | The one-sheet board: factions, world tone, visual pillars, palettes, example subjects, atmosphere, the eight visual laws. |

The order of precedence, from the project README: **the lore, then the Art
Direction Guide, then the sigils, then the naval master.** And above all of
them, Sean's newest explicit decision — *"When a new request conflicts with an
established rule, follow the user's newest explicit decision. Otherwise
preserve the existing canon."*

`../lore.md` is the first of those four. It has been brought into line with the
other three; the sections that carry a rule from one of them say so.
