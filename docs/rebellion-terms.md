# Rebellion → Seven Seas, a translation table

Sean thinks in *Star Wars: Rebellion* (1998), because that is the game this one
is modelled on. He says so himself: *"I use a lot of SW Rebellion terms. So you
should note from a dev perspective which ones mean same thing."*

So this file is for me, not for the player. Two jobs:

1. **Understand him.** When he says "regiment" he means a Troop, and the
   right response is to do the Troop thing, not to ask which he means.
2. **Correct him, lightly.** He asked to be corrected when he uses a word the
   game no longer uses. One clause, in passing, and then get on with the work
   — *"(that's a Troop now)"* — never a lecture and never a blocked answer.

Nothing in this table is allowed anywhere a player can see it. The left column
is somebody else's trademarked game.

## Things Rebellion has that we do not

Fighters and squadrons, energy/mineral as two resources (we have gold only),
planetary shields as a separate layer from guns, the Death Star, droids,
sector-wide "influence" as a number the player reads.

## And one we have that it does not

The **watch** — how closely an island is being watched, which every covert
errand must get past before it is even attempted.
